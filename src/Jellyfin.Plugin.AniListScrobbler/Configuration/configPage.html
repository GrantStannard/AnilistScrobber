Account

Each Jellyfin user links their own AniList account. Settings below apply to the selected user.
Paste a token, or use the authorize link below to get one.

Getting a token

Create an API client at anilist.co/settings/developer. Set the redirect URL to https://anilist.co/api/v2/oauth/pin and copy the client id and secret here.

Save, then open the authorization page, approve access, and paste the PIN below.

Scrobbling

How much of an episode must play before it counts as watched.
Select nothing to scrobble every library. Hold Ctrl to select several.

Matching

Required for libraries whose metadata comes from AniDB or Shoko. The dataset is fetched from Fribb/anime-lists and cached on the server.
Between 0 and 1. Lower accepts looser matches and risks scrobbling the wrong show.

Manual mappings

Pin a Jellyfin series or season to a specific AniList entry. Use the offset when a library numbers episodes continuously across seasons: a season whose first episode is numbered 26 in Jellyfin but 1 on AniList needs an offset of 25.
